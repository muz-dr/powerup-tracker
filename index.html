AI Helper

🤖 Gemini AI Nutrition Tracker

Use Google Gemini to automatically estimate daily nutrition from meal photos or descriptions, then import here in one tap.

📋 How to use

1
Open Google Gemini — go to gemini.google.com or the Gemini app. Use Gemini 1.5 Pro or higher for best accuracy.
2
Copy and send the prompt below — tap Copy Prompt, paste into Gemini, and send. This sets Gemini up to track your meals.
3
Log each meal as you eat — send a photo or describe it in text (e.g. "Nasi Lemak with fried egg"). Gemini keeps a running tally.
4
At end of day, type "Final Summary" — Gemini replies with a JSON block of your totals.
5
Tap 🤖 Gemini Fill above — paste the JSON into the popup. Form fills automatically. Review, then tap Log Day.
💡 Pro tip — use AI Mode Search: In the Gemini app, enable the Search toggle so Gemini can look up nutritional data for branded foods and restaurant meals in real time for much more accurate values.

📋 Prompt to copy

I will send you photos or descriptions of my breakfast, lunch, dinner, and snacks throughout the day. For EVERY meal I send, you must strictly follow these two steps: 1. Break down the estimated calories, protein, carbs, fat, and sodium for each ingredient. Explicitly look out for hidden Malaysian cooking variables like cooking oils, santan, and sugar coatings based on standard local recipes. 2. Run a Python script internally to calculate and verify the exact running sum of the day so far. Do not do the math using text prediction. When I say "Final Summary", use Python to generate the final verified numbers and output them strictly inside a JSON code block using exactly this format: ```json { "calories": [Total], "protein": [Total], "carbs": [Total], "fat": [Total], "sodium": [Total] } ``` Use whole numbers only. Do not include units inside the values. Start tracking now.
